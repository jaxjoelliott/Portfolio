# Portfolio – jacksonelliott.netlify.app

Personal portfolio site template built with React + Vite + TypeScript.

## Live Site
https://jacksonelliott.netlify.app

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Netlify (auto-deploy from GitHub)

## Local Development
```bash
npm install
npm run dev
```

## Structure
```
src/
├── components/    # UI components
├── data/          # data.json — edit this to update content
├── routes/        # Page routing
public/
├── images/        # Project screenshots and profile photo
├── resume/        # Resume PDF
```

## Updating Content
Almost everything is driven by `src/data/data.json` — projects, experience, skills, education. Edit that file and push to update the live site.

## Deployment
Connected to Netlify. Every push to `main` auto-deploys.
